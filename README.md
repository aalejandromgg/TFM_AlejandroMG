# TFM_AlejandroMG
Código realizado para el TFM de Alejandro Muñoz García: Detección de anomalías en redes de telecomunicaciones mediante Análisis de Datos Funcionales y Aprendizaje Automático

Se aportan los ficheros que se  usan para la realización de este trabajo:
 - 3_3DatosFuncionales.ipynb: Fichero donde se aplican las bases de Fourier y B-Splines a las series temporales de una variable, se representan, se comparan y por último hay un apartado donde se analiza el número de bases óptimo.
 - 3_4_1ClusterizacionSemanas: Fichero donde se diferencian los tipos de semanas de una institución, los tipos de instituciones y un apartado de detección de anomalías con umbrales.
 - 3_4_2ClusterizacionSemanas: Fichero donde se aplica FPCA para poder determinar según las componentes principales, los comportamientso generales de una semana, de una institución...
 - 3_4_3Correlación y 3_4_3Covarianza: Ficheros orientados al análisis multivariante, sacando los pares con valores más altos y analizándolos para determinar comportamientos anómalos.
